# Audio Design & Manifest Generation Skill

## Operational Directives
1. Inspect the workspace for existing `audio_manifest.json` or sound assets.
2. Formulate high-fidelity cinematic Foley and sound design prompts.
3. Generate structured audio manifests with `id`, `category`, `duration_ms`, `cue_point`, and `prompt`.
4. Output valid JSON adhering to standard audio schema.
